# Basic Setup sample

1. Configure the endpoint and key in **Project Settings > Playtest Telemetry**.
2. Add the `PLAYTEST_TELEMETRY` define (**Tools > Playtest Telemetry > Add define**).
3. Put `BasicSetupDemo` on a GameObject in any scene and press Play (or make a Development build).
4. Press the buttons, then check the `issues` / `v_sessions` views in Supabase or the Grafana dashboards.
